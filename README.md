# Ponchopig Yams

## How do I install these formulae?

`brew install ponchopig/yams/<formula>`

Or `brew tap ponchopig/yams` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "ponchopig/yams"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
